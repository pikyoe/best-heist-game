# Velvet Vault — a midnight heist

A complete, original top-down stealth heist game, built for the
[make.fun best heist game competition](https://make.fun/c/best-heist-game-20261122-0559).
You are Rook, a thief crossing three wings of the Meridian Museum after dark:
read the guards' vision cones, slip past the sweeping cameras, lift the prize,
and vanish through the exit before the alarm hits full lockdown.

## How to play

Open `game/index.html` in desktop Chrome — no build step, no network requests.
Everything (art, sound, levels) is generated by the game's own code.

- **WASD / arrows** — move
- **Shift** — sneak (slower, harder to spot, alarm climbs slower)
- **Click** — toss a distraction coin; the nearest guard goes to investigate (costs $25)
- **Space** — drop a smoke pellet that blinds guards and cameras (costs $50)
- **R** — restart the floor, **M** — mute, **Enter** — advance

## The heist

Three floors, each a different wing with its own patrols, cameras, lasers and
prize: the Star Sapphire, the Tide Crown, the Gilded Scepter. Side loot (a
portrait, a gold bar, a ruby tiara…) pays extra; tools cost score, so every
coin and pellet is a decision. The alarm meter climbs while any guard or
camera holds you in its cone and falls while you stay hidden. At 100 the
museum locks down and every guard runs to where they last saw you — break
line of sight for 8 seconds to slip the lockdown. Touch a guard and you are
caught.

## Files

- `game/` — the playable game (`index.html` + `src/` modules, one clear job each)
- `screenshots/` — 4 real renders of the game's own code
- `main.ts` — the Node 22 hand-in program: copies `game/` and `screenshots/`
  to `/output` and writes `/output/dossier.json` (run with
  `MAKEFUN_OUTPUT_DIR=out node main.ts`)
- `vendor/makefun-game.ts` — the kit's dossier library, copied unchanged
